# MiPan 2025 Store

Proyecto base para una tienda online de Panadería MiPan 2025 C.A. compatible con GitHub Pages.

## Estructura

- `index.html`: página principal de la tienda
- `admin.html`: panel para administrar productos y stock
- `manifest.json`: configuración de PWA
- `sw.js`: service worker para carga offline
- `assets/css/styles.css`: estilos del branding y diseño de la tienda
- `assets/js/data.js`: catálogo base de productos
- `assets/js/app.js`: lógica de la tienda y carrito
- `assets/js/admin.js`: lógica del panel administrativo
- `assets/images/`: carpeta de imágenes e iconos

## Funcionalidades base

- catálogo con categorías
- carrito de compras local
- pedidos por WhatsApp
- filtro por búsqueda y categoría
- panel de administración con almacenamiento local
- compatibilidad PWA para GitHub Pages

## Despliegue

Este sitio está pensado para publicarse en GitHub Pages usando archivos estáticos.
